# Urban Temporalities — Visual Essay

**The City Does Not Contain the Life** is an authored visual essay by Kabiri N. Bule (October 2026), developed from the Urban Temporalities research programme across Accra, Johannesburg and Nairobi.

Its interactive centrepiece, the **Atlas of Urban Elsewheres**, asks a simple question: where does the city end when the geographies of everyday life extend beyond administrative, built-up and functional boundaries?

## Public site

GitHub Pages can serve the essay directly from the `main` branch at the repository root.

## Files

- `index.html` — visual essay
- `atlas.html` — interactive Atlas of Urban Elsewheres
- `assets/` — photographic assets used by the essay
- `.nojekyll` — serves the static site without Jekyll processing

## Publication note

The public interface uses aggregate spatial data and disclosure rules designed to avoid respondent-level identification. Photographic and data attributions are included in the essay.
